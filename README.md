# HTML, CSS, and JavaScript UI Components

A collection of small, dynamic UI components built with **HTML**, **CSS**, and **JavaScript**.  
Each component is fully responsive and can be integrated into other projects.

---

## 📂 Components

| Component Name         | Description |
|------------------------|-------------|
| **Accordion**          | Expand/collapse sections with smooth animations. |
| **Age Calculator**     | Calculates age based on selected date of birth. |
| **Cookie Consent**     | Displays a cookie consent banner with dismiss functionality. |
| **Guess Word**         | Simple word-guessing game with dynamic feedback. |
| **Memory Block**       | Memory-matching card game. |
| **Restricted Textarea**| Limits characters in a textarea with a live counter. |
| **Tabs**               | Tabbed content navigation. |
