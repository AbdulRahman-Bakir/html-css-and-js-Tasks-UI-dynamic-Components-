# HTML, CSS, and JavaScript UI Components

A collection of small, dynamic UI components built with **HTML**, **CSS**, and **JavaScript**.  
Each component is fully responsive and can be integrated into other projects.

---

## 📂 Components

| Component Name         | Description | Project Link |
|------------------------|-------------|--------------|
| **Accordion**          | Expand/collapse sections with smooth animations. | [roadmap.sh](https://roadmap.sh/projects/accordion) |
| **Age Calculator**     | Calculates age based on selected date of birth. | [roadmap.sh](https://roadmap.sh/projects/age-calculator) |
| **Cookie Consent**     | Displays a cookie consent banner with dismiss functionality. | [roadmap.sh](https://roadmap.sh/projects/cookie-consent) |
| **Guess Word**         | Simple word-guessing game with dynamic feedback. | — |
| **Memory Block**       | Memory-matching card game. | — |
| **Restricted Textarea**| Limits characters in a textarea with a live counter. | [roadmap.sh](https://roadmap.sh/projects/restricted-textarea) |
| **Tabs**               | Tabbed content navigation. | [roadmap.sh](https://roadmap.sh/projects/simple-tabs) |
